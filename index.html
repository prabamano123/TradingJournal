Google Drive configuration

Your trades are stored in a single file called trading_journal.json in your Google Drive root. The app reads and writes this file directly using the Google Drive API. Your data never touches any third-party server.

1
Create a Google Cloud project Go to console.cloud.google.com → New Project → give it any name (e.g. "Trading Journal")
2
Enable the Google Drive API APIs & Services → Library → search "Google Drive API" → Enable
3
Configure OAuth consent screen APIs & Services → OAuth consent screen → External → Fill in App name → Add your Gmail address as a Test user → Save
4
Create OAuth 2.0 credentials Credentials → Create Credentials → OAuth 2.0 Client ID → Application type: Web application
Under "Authorized JavaScript origins" add: http://localhost and the URL where you host this file (e.g. file:// won't work — host it at http://localhost using a simple server, or use GitHub Pages / Netlify)
5
Paste your Client ID below Copy the Client ID (ends in .apps.googleusercontent.com) and paste it into the field on the sign-in screen or here
6
Easiest way to run locally In your terminal: cd /folder/with/this/file && python3 -m http.server 8080 then open http://localhost:8080/trading_journal.html
